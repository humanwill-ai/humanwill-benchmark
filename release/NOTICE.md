# Release status and rights

HumanWill Benchmark — Measuring harmful refusals in AI models.

The [v0.1.0a11 product release](https://github.com/humanwill-ai/humanwill-benchmark/releases/tag/v0.1.0a11)
provides the framework wheel, curated source archive and approved reference-pack
ZIP. GitHub is the distribution channel; PyPI is deferred. The software and
question-pack artifacts preserve their original versioned bytes and notices.

Software, documentation, examples, tests and tools use Apache 2.0; the harmless
demo and HumanWill's licensable rights in the reference pack use CC BY 4.0.
Preserve HumanWill / https://humanwill.ai attribution. See
[license scope](../LICENSING.md), [Apache terms](../LICENSE), [NOTICE](../NOTICE)
and [brand guidance](../BRAND.md). Trademark rights remain separate.

The approved reference pack is included in the Git checkout and separate ZIP;
it is excluded from the framework wheel and curated source archive. Its questions
and exact policy completed internal owner review with self-declared expertise,
not an independently verified external audit. The unchanged delivery carries
provenance and redacted review hashes. Personal reviewer records, historical
model answers, private experiments and research Git history are excluded.

The software was extracted from HumanWill's research implementation; module
docstrings preserve lineage. No upstream benchmark prompts or vendored runtime
dependencies are included. Third-party material retains its applicable rights.

The source inventory and checksum checks limit accidental inclusion; they are
not comprehensive secret detection, legal review or security certification.
Keep private submissions, credentials and model responses out of issues and
pull requests. No private submission channel or support service is promised.
