# Harmless local demonstration

Three original, AI-assisted HumanWill echo tasks demonstrate exact message
delivery, stable identifiers and separate candidate/judge operations. They are
not cybersecurity questions, reference labels for real models, or a calibrated
benchmark. The simulated judge uses an explicit mock behavior signal and exact
echo equality; it never classifies refusal by searching for phrases.
