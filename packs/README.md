# HumanWill question packs

The approved [cybersecurity reference delivery 0.1.0](https://github.com/humanwill-ai/humanwill-benchmark/tree/main/packs/cybersecurity/0.1.0)
contains all 424 questions and the exact reviewed judging policy.
Use the current [reference benchmark quick start](../docs/REFERENCE_BENCHMARK.md).

The versioned directory preserves every original delivery byte, including its
historical README links. Current installation instructions live outside that
immutable directory. The pack is separate from the software wheel/source archive.
Personal review records, historical model answers and private submissions are
not included. See [license scope](../LICENSING.md) and
[pack authoring and extensions](../docs/PACK_ACCESS.md).
